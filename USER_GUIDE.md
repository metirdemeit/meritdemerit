# Merits & Demerits — user guide

The illustrated user guide for students, teachers and administrators lives in
[`public/guide/index.html`](public/guide/index.html) and is served with the app at
**`/guide/index.html`**.

Inside the app:

- the `?` button on each dashboard replays the step-by-step tour for your role;
- the tour's last step and the login page link to the full guide.

When the UI changes, update the screenshots in `public/guide/img/` together with the text.
